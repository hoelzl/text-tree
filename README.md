# Text Tree

This is a very simple program to edit text in a tree structure. Eventually,
hopefully with support from LLMs.

## Usage

If you're using uv:

```bash
uv run python run.py
```

Then browse to `http://localhost:8050` and marvel at one of the worst user
interfaces ever designed.

You can load `dialogue_graph_01.json` to see a sample dialogue graph.

## Running the tests

```bash
uv run pytest
```
